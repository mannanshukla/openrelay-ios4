Five minutes to install.

One setup. All five apps.

  1. Start from a jailbroken iPod touch 4 or iPhone 4 on iOS 4.3. Legacy iOS Kit handles the downgrade and the jailbreak.
  2. Install AppSync for iOS 4, then TLSFix from cydia.skyglow.es and the certificate bundle at tlsroot.litten.ca. This gives iOS 4 modern HTTPS.
  3. Download an app and install it: ideviceinstaller install OpenRelay-1.1.ipa
  4. Enter your OpenRelay API key in the app's Settings. One key works for all five. Laya Ball uses it too.
